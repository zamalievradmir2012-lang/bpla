# «БЕСПИЛОТНИКИ» — игра для Roblox Studio

Командный экшен **Операторы БПЛА vs Защитники ПВО**: операторы управляют 10 типами ударных
дронов из подземного бункера и разрушают детализированный город 2048×2048 studs, защитники
отбивают налёт из стрелкового оружия, ПЗРК и зенитных комплексов. Раунды по 10 минут,
экономика с сохранением через DataStore, мега-разрушения зданий с обрушением этажей,
пожарами и воронками.

---

## 🚀 Установка (1 минута)

1. Откройте **Roblox Studio** → `File → Open from File…`
2. Выберите файл **`БЕСПИЛОТНИКИ.rbxlx`** (лежит рядом с этим README).
3. Нажмите **Play (F5)** — город сгенерируется автоматически при старте сервера.
4. Для сохранения монет между запусками: `Game Settings → Security → Enable Studio Access to API Services = ON`
   (нужен опубликованный опыт: `File → Publish to Roblox`).
5. Для публикации: `File → Publish to Roblox As…` → включите сервер (Play → кнопка Start с 2+ игроками для проверки кооператива).

Все 13 скриптов уже встроены в файл карты. Исходники лежат в `src/` — если удобнее
править код в Studio, просто откройте соответствующий Script/LocalScript в Explorer.

## 🎮 Управление

### Операторы БПЛА (в бункере открывается магазин, клавиша **B** — открыть/закрыть)

**Тип A — WASD** («Пчела», «Орлан», «Иноходец», «Охотник», лидер «Саранчи»):
| Клавиша | Действие |
|---|---|
| W / S | вперёд / назад |
| A / D | поворот (yaw) |
| Пробел / Shift | набор / снижение высоты |
| ЛКМ | сброс бомбы / гранаты / пуск ракеты / атака роя |
| E | («Орлан») подвесная камера: колесо — зум, ЛКМ — маркер цели для союзников |
| R | («Охотник») бомбы ⇄ крылатые ракеты |
| G | («Саранча») строй роя: клин ⇄ облако |
| X | возврат на базу (посадка возвращает 50% цены) |

**Тип B — FPV-мышь** («Упырь», «Герань-1/2», «Ланцет», «Молния»):
- Курсор смещён от центра экрана → дрон кренится и поворачивает в эту сторону (чем дальше — тем сильнее).
- **W / S** — газ больше/меньше. **ЛКМ** — подрыв (камикадзе взрываются и от столкновения автоматически).
- **C** — («Ланцет») барражирование: дрон кружит, ждёт цель.

### Защитники ПВО
| Клавиша | Действие |
|---|---|
| 1..3 / бэкпак | АК-74М, Корд (замедляет 50%), ПЗРК «Игла-С» |
| ЛКМ (удерж.) | огонь очередями / наведение ПЗРК (держать на дронe 2 c до захвата) |
| R | перезарядка |
| V | вид от 1-го/3-го лица |
| **E** | сесть за ЗУ-23-2 / «Панцирь-С1» / прожектор |
| за зениткой | мышь — наведение, ЛКМ — огонь; на «Панцире» ПКМ (удерж.) — захват под ракету |
| X | встать с прожектора |
| B | магазин улучшений защитника (броня +50 HP, ускоренная перезарядка ПЗРК, бронещит, ремкомплект зенитки) |
| Tab | табло игроков |

## 💰 Экономика (как в ТЗ)

- **Операторы**: разрушение дома +40 / многоэтажки +80 / промобъекта +60 / зенитки +100 /
  моста +120 / ТЦ +150; убийство защитника +25; 1 очко за каждую разрушенную часть.
- **Защитники**: сбитый дрон +30…+200 (по классу), +10 за каждые 60 c выживания,
  +50 всем защитникам, если разрушено <20% города.
- Монеты сохраняются через DataStore (`BespilotnikiCoins_v1`).

## ⚙️ Известные упрощения (и как их доработать)

| ТЗ | Реализация | Где доработать |
|---|---|---|
| SurfaceAppearance на фасадах | Материал Glass + Reflectance (не требует загрузки текстур) | `MapGenerator.glassTower` |
| PointLight в 60% окон | 60% окон светятся неоном (без источников света — иначе киллер-фреймрейт), точечные источники — только фонари | `Main.setNight` |
| Звуки моторов/взрывов | База — встроенные `rbxasset://` (работают всегда) + классические ID. **Замените на свои из Toolbox** | `Config.SOUNDS` — один словарь |
| Радар обновляется 2 c (дождь не замедляет) | фиксированные 2 c | `DroneService.fuelAndRadarLoop` |
| Подсветка дрона прожектором → маркер всем | луч есть, GUI-маркер над дроном не вешается | `WeaponService.handleGunAim` + `DroneService` |
| Голосование за карту | после раунда город всегда пересобирается тот же | `Main.playRound` → подключите свои варианты генератора |
| Slow-motion киллкама | эффектный «наезд» FOV (реального замедления сервера нет) | `DroneController` (OperFX "dead") |
| Патфайндинг жителей (PathfindingService) | прямые MoveTo по тротуарам — дешевле | `NpcService.wander` |
| Античит стрельбы | серверная валидация темпа/дистанции, без серт. анализа траекторий | `WeaponService.handleWeaponFire` |

## 🔧 Быстрая настройка

- Скорость/урон/цены любого дрона — `src/ReplicatedStorage/Shared/Config.lua` → `Config.DRONES`.
- Длительность раунда — `Config.ROUND_TIME` (сек), длина суток — `Config.DAY_CYCLE`.
- Чувствительность FPV — `DroneController.client.lua`, `delta.X * 6` (коэффициент).
- После правок `src/` пересоберите карту: `python3 build_place.py`.
